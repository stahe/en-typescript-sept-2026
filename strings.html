    6. Strings

    The scripts in this chapter are located in the [strings] folder of the project.

    6.1. script [str-01]

    The first thing to understand is that once a string is created, it can no longer be modified (it is immutable). There are many methods available to create a new string from the original string, but the original string always remains unchanged.

      1  'use strict';
  2  
  3  // the strings are read-only (they cannot be modified)
  4  
  5  // a string
  6  const chaîne1: string = "abcd ";
  7  // type
  8  console.log("typeof(chaîne1)=", typeof (chaîne1));
  9  // character #2
 10  console.log("chaîne1[2]=", chaîne1[2]);
 11  // causes an error
 12  // [mise à jour TypeScript] TypeScript detects the error during compilation:
 13  // a string has read-only access by index
 14  // @ts-expect-error: a string is read-only
 15  chaîne1[2] = "0";
    • Line 10: string1[2] reads the third character of the string (index 0);
    • Line 15: string 1[2] = "0" attempts a write operation, which TypeScript rejects at compile time, thanks to @ts-expect-error—the comment above confirms that this error is expected and is intended precisely to demonstrate it.

    Type checking:

    npx tsc --noEmit

    Execution result:

      1  strings/str-01.ts(15,1): error TS2540: Cannot assign to '2' because it is a read-only property.

    Execution with tsx (without prior type checking):

    npx tsx strings/str-01.ts

    Execution result:

      1  typeof(chaîne1)= string
  2  chaîne1[2]= c
  3  TypeError: Cannot assign to read only property '2' of string 'abcd '
  4      at strings/str-01.ts:15:10

    6.2. script [str-02]

    A character string can be one of two types: [string] (literal string) or [object] (instance of the [String] class):

      1  'use strict';
  2  
  3  // String literals can be of two types
  4  
  5  // a string literal
  6  const chaîne1: string = "abcd ";
  7  // type
  8  console.log("typeof(chaîne1)=", typeof (chaîne1));
  9  // String instance
 10  // eslint-disable-next-line @typescript-eslint/ban-types -- here, [String] (object) is the exact type needed, not [string] (primitive): that is precisely the point of the demo
 11  const chaîne2: String = new String("xyzt");
 12  // type
 13  console.log("typeof(chaîne2)=", typeof (chaîne2));
 14  // alternative notation (without `new`)
 15  const chaîne3: string = String("12 34");
 16  // type
 17  console.log("typeof(chaîne3)=", typeof (chaîne3));
 18  // The type [string] and the type [object] offer the same methods—those of the String class
 19  console.log("chaîne1.length=", chaîne1.length);
 20  console.log("chaîne2.length=", chaîne2.length);
    • Line 6: the standard way to define a string—string1 will be of type string;
    • line 12: new String(...)</span> creates a string object—string2 will be of type object. Here, the declared type TypeScript is String (with a capital S), the *wrapper object* type, which is different from the primitive type string (lowercase);
    • both types offer the same methods—those of the String class.
    npx tsx strings/str-02.ts

    Execution result:

      1  typeof(chaîne1)= string
  2  typeof(chaîne2)= object
  3  typeof(chaîne3)= string
  4  chaîne1.length= 5
  5  chaîne2.length= 4

    6.3. script [str-03]

    This script demonstrates variable interpolation in a string:

      1  'use strict';
  2  
  3  // string
  4  const chaîne: string = "Introduction à Javascript par l'exemple";
  5  // string with variable interpolation
  6  const str: string = `[${chaîne}].substr(3, 2)=` + chaîne.substr(3, 2)
  7  console.log(str);
    • Line 6: A string enclosed in backticks (*backticks*, AltGr-7 on a French keyboard) can contain ${variable} expressions, which are replaced by the variable’s value—this is called a template string.
    npx tsx strings/str-03.ts

    Result of execution:

      1  [Introduction à Javascript par l'exemple].substr(3, 2)=ro

    6.4. script [str-04]

    The template string alone is insufficient for precise formatting (width, alignment, decimal precision, etc.). For this purpose, we use an external package, [sprintf-js], which replicates the printf/sprintf functions familiar from other languages. It is installed with <span style="color: #9a3412">npm install sprintf-js</span> and can be easily imported:

      1  'use strict';
  2  // Using an external package to access the sprintf function
  3  import { sprintf } from 'sprintf-js';
  4  // string
  5  const chaîne: string = "Introduction à Javascript par l'exemple";
  6  // method
  7  console.log(sprintf("[%s].substr(3,2)=[%s]", chaîne, chaîne.substr(3, 2)));
    Background: In 2019, the `import` statement caused issues with Node.js (which did not yet natively support modules, as seen in ECMAScript), and required an intermediate package called `esm`. This is no longer the case as of Node 12+: our project, with "type": "module" in package.json, uses import/export natively, without any additional configuration.
    npx tsx strings/str-04.ts

    Execution result:

      1  [Introduction à Javascript par l'exemple].substr(3,2)=[ro]

    6.5. script [str-05]

    The [sprintf] function accepts, as in C, "formats" introduced by %: %s (string), %d (integer), %f (floating-point), %j (JSON), %T (type), %t (boolean), along with width and alignment modifiers (%20s, %-20s, %04d...):

      1  'use strict';
  2  // Using an external package to access the sprintf function
  3  import { sprintf } from 'sprintf-js';
  4  // string
  5  const chaîne: string = "Javascript";
  6  // strings
  7  console.log(sprintf("[%s, %%s]=>[%s]", chaîne, chaîne));
  8  console.log(sprintf("[%s, %%20s]=>[%20s]", chaîne, chaîne));
  9  console.log(sprintf("[%s, %%-20s]=>[%-20s]", chaîne, chaîne));
 10  // integers
 11  console.log(sprintf("[%d, %%d]=>[%d]", 10, 10));
 12  console.log(sprintf("[%d, %%4d]=>[%4d]", 10, 10));
 13  console.log(sprintf("[%d, %%-4d]=>[%-4d]", 10, 10));
 14  console.log(sprintf("[%d, %%04d]=>[%04d]", 10, 10));
 15  // floating-point numbers
 16  console.log(sprintf("[%f, %%f]=>[%f]", -10.5, -10.5));
 17  console.log(sprintf("[%f, %%10.2f]=>[%10.2f]", -10.5, -10.5));
 18  console.log(sprintf("[%f, %%-10.2f]=>[%-10.2f]", -10.5, -10.5));
 19  console.log(sprintf("[%f, %%010.3f]=>[%010.3f]", -10.5, -10.5));
 20  // json
 21  console.log(sprintf("personne (%%j)=%j", { nom: "mathieu", âge: 34 }));
 22  // type
 23  console.log(sprintf("type personne (%%T)=%T", { nom: "mathieu", âge: 34 }));
 24  // boolean
 25  console.log(sprintf("booléen (%%t)=%t", 4 === 4));

    6.6. [str-06] script

    This script lists the most common methods of the [String] class:

      1  'use strict';
  2  // Using an external package to access the sprintf function
  3  import { sprintf } from 'sprintf-js';
  4  // string
  5  const chaîne: string = "  Introduction à Javascript ";
  6  // a few methods
  7  // substr(10,2): 2 characters starting at position 10
  8  console.log(sprintf("[%s].substr(10,2)=[%s]", chaîne, chaîne.substr(10, 2)));
  9  // trim: removes whitespace at the beginning and end of a string (whitespace = \b \t \r \n \f)
 10  console.log(sprintf("[%s].trim()=[%s]", chaîne, chaîne.trim()));
 11  // toLowerCase: conversion to lowercase
 12  console.log(sprintf("[%s].toLowerCase=[%s]", chaîne, chaîne.toLowerCase()));
 13  // toUpperCase: conversion to uppercase
 14  console.log(sprintf("[%s].toUpperCase=[%s]", chaîne, chaîne.toUpperCase()));
 15  // indexOf: position of a searched string within the string; -1 if the substring does not exist
 16  console.log(sprintf("[%s].indexOf('Java')=[%s]", chaîne, chaîne.indexOf('Java')));
 17  console.log(sprintf("[%s].trim().indexOf('abcd')=[%s]", chaîne, chaîne.indexOf('abcd')));
 18  // includes: true if the searched string is in the string
 19  console.log(sprintf("[%s].includes('Java')=[%s]", chaîne, chaîne.includes('Java')));
 20  // length: length of the string—this is not a method but a property
 21  console.log(sprintf("[%s].length=[%s]", chaîne, chaîne.length));
 22  // slice (7,10): characters 7 through 9
 23  console.log(sprintf("[%s].slice(7,10)=[%s]", chaîne, chaîne.slice(7, 10)));
 24  // match: searches for an expression in the string—this expression can be a regular expression
 25  // /intro/i: regular expression matching the string [intro] in either uppercase or lowercase
 26  // returns the found string
 27  console.log(sprintf("[%s].match(/intro/i)=[%s]", chaîne, chaîne.match(/intro/i)));
 28  // replace: replaces string1 with string2 in string
 29  // replaces the first occurrence of i with x
 30  console.log(sprintf("[%s].replace('i','x')=[%s]", chaîne, chaîne.replace('i', 'x')));
 31  // replaces all occurrences of i with x
 32  // /i/g is a regular expression that matches all (g) occurrences of i
 33  console.log(sprintf("[%s].replace(/i/g,'x')=[%s]", chaîne, chaîne.replace(/i/g, 'x')));
 34  // split: splits the string into words separated by the split parameter
 35  // returns an array of these words
 36  // /\s*/: words separated by zero or more spaces
 37  console.log(sprintf("[%s].split(/\\s*/)=[%s]", chaîne, chaîne.split(/\s*/)));
 38  // /\s+/: words separated by one or more spaces
 39  console.log(sprintf("[%s].split(/\\s+/)=[%s]", chaîne, chaîne.split(/\s+/)));
    • [trim] removes leading and trailing whitespace; [toLowerCase]/[toUpperCase] change the case;
    • [indexOf] returns the position of a substring (-1 if absent); [includes] returns a Boolean;
    • [slice] extracts a substring by position; [match] matches the string against a regular expression (see next chapter);
    • [replace] replaces the first occurrence found (or all occurrences, with a /g regex); [split] splits the string into an array of words.
    npx tsx strings/str-06.ts

      1  [  Introduction à Javascript ].substr(10,2)=[ti]
  2  [  Introduction à Javascript ].trim()=[Introduction à Javascript]
  3  [  Introduction à Javascript ].toLowerCase=[  introduction à javascript ]
  4  [  Introduction à Javascript ].toUpperCase=[  INTRODUCTION À JAVASCRIPT ]
  5  [  Introduction à Javascript ].indexOf('Java')=[17]
  6  [  Introduction à Javascript ].trim().indexOf('abcd')=[-1]
  7  [  Introduction à Javascript ].includes('Java')=[true]

    6.7. script [str-07]

    [NOUVEAU depuis 2019] Three new features introduced between 2020 and 2024: [replaceAll], [matchAll], and the detection/correction of “malformed” strings:

      1  'use strict';
  2  // ========================================================================
  3  // [NOUVEAU depuis 2019] new string methods
  4  // ========================================================================
  5  
  6  // ------------------------------------------------------------------------
  7  // 1) replaceAll (search, replace)  (ECMAScript 2021)
  8  // ------------------------------------------------------------------------
  9  // str-06.js shows that replace() with a string only replaces the first occurrence
 10  // and that a regular expression with /i/g was needed to replace everything
 11  const chaîne: string = "un chat, deux chats, trois chats";
 12  console.log("replace (1 seule occurrence) :", chaîne.replace("chat", "chien"));
 13  console.log("replaceAll (toutes les occurrences) :", chaîne.replaceAll("chat", "chien"));
 14  // replaceAll also accepts a regular expression, but it must have the flag [g]
 15  console.log("replaceAll avec regexp :", chaîne.replaceAll(/chat/g, "chien"));
 16  
 17  // ------------------------------------------------------------------------
 18  // 2) matchAll(regexp)  (ECMAScript 2020)
 19  // ------------------------------------------------------------------------
 20  // `match()` with the `[g]` flag returns only the matched strings, without their positions or groups
 21  // matchAll() returns an iterator that provides, for each occurrence, all the information (like exec())
 22  const texte: string = "Jean a 30 ans, Marie a 25 ans, Paul a 40 ans";
 23  const modèle: RegExp = /(\w+) a (\d+) ans/g;
 24  
 25  // With `match` (flag `g`): the details of the captured groups are lost
 26  console.log("match =", texte.match(modèle));
 27  
 28  // with matchAll: the details are retained (captured name, captured age, position...)
 29  console.log("-----------------------");
 30  for (const résultat of texte.matchAll(modèle)) {
 31    console.log("nom =", résultat[1], ", âge =", résultat[2], ", position =", résultat.index);
 32  }
 33  
 34  // You can also convert the iterator into an array using the spread operator
 35  const tousLesRésultats = [...texte.matchAll(modèle)];
 36  console.log("nombre de correspondances =", tousLesRésultats.length);
 37  
 38  // ------------------------------------------------------------------------
 39  // 3) isWellFormed() / toWellFormed()  (ECMAScript 2024)
 40  // ------------------------------------------------------------------------
 41  // A string JavaScript may contain an isolated invalid "half-Unicode character"
 42  // (for example, when a string has been improperly split). This can cause
 43  // certain functions (encodeURIComponent, ...)
 44  const chaîneValide: string = "café ☕";
 45  const chaîneMalFormée: string = "abc\uD800def"; // \uD800 is an isolated “half-character” that is invalid on its own
 46  
 47  console.log("chaîneValide.isWellFormed() =", chaîneValide.isWellFormed());
 48  console.log("chaîneMalFormée.isWellFormed() =", chaîneMalFormée.isWellFormed());
 49  
 50  // toWellFormed() replaces invalid characters with the replacement character �
 51  console.log("chaîneMalFormée.toWellFormed() =", chaîneMalFormée.toWellFormed());
    • [replaceAll] (ES2021) replaces all occurrences of a string without requiring a /g regular expression, as in the str-06 script;
    • [matchAll] (ES2020) returns an iterator of all results found, each with its captured groups ET and its position—whereas <span style="color: #9a3412">match with the g flag returns only the found strings, without this detail;
    • [isWellFormed]/[toWellFormed] (ES2024) detects and corrects strings containing an isolated “half Unicode character” (often caused by incorrect string splitting), which can cause certain functions—such as encodeURIComponent—to crash.
